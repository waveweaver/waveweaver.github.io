3GPP RAG

A local question-answering system over 3GPP technical specifications. It combines BM25 sparse retrieval and ChromaDB vector search, fused with Reciprocal Rank Fusion, and answers with a local LLM through Ollama.

  • Parses .docx and .pdf specs into 1,000-character chunks with 200 overlap, then indexes them for both retrievers.
  • Fetches 6 candidates per retriever and sends the top 5 chunks to the LLM after fusion.
  • Runs fully locally with Ollama (llama3.2:3b for answers, nomic-embed-text for embeddings).

Real-time systems

resumable

Server-sent events with a real Last-Event-ID contract over a bounded replay buffer. When the resume point has been evicted, the server sends an explicit GAP signal, so a reconnecting client never silently skips events.

  • In a seeded demo, 24,540 events were published during repeated reconnects; this implementation delivered all of them.
  • A test suite checks 1,000 scripted disconnects for zero lost events, zero duplicates and strict ordering.
  • Three distinct resume outcomes: FRESH, RESUMED and GAP.

Developer tools

locksmith

A migration linter that parses PostgreSQL migration SQL and predicts which lock each statement takes, whether it blocks reads or writes on the target server version, and roughly how long it holds the lock on a table of a given size.

  • Classifies statements into 18 operation kinds and encodes the lock conflict matrix as data.
  • In the demo, a 400M-row table's total write-blocking time is 56.7 min on PostgreSQL 10 and 6.7 min on PostgreSQL 16.
  • 41 tests; unrecognised statements are treated as worst case, never as safe.
  • TypeScript
  • PostgreSQL
  • SQL
  • Node.js
  • GitHub Actions

Backend & data modeling

ratevault

A motor insurance quote engine with bitemporal rate tables, so any past quote can be repriced exactly using the rates and rules in force at the time. Each rate carries a valid-time and a transaction-time range, and rows are closed, never updated or deleted.

  • Separates what was quoted (GBP 1995.19 in the demo) from what should have been quoted after a backdated correction (GBP 1671.64).
  • A database trigger rejects overlapping valid-time ranges, and issuance is idempotent on a client token.
  • Every price comes back with the multiplier and running total of each rating factor.
  • TypeScript
  • SQLite
  • Bitemporal data
  • Node.js

blastgraph

Cloud IAM analysis that models an estate as a privilege graph and finds multi-hop escalation paths to crown-jewel resources. It ranks which single permission to remove to break the most paths.

  • On a sample estate of 14 principals, 19 edges and 3 crown jewels, it reports 6 paths for an outside attacker.
  • Removing the top-ranked edge eliminates 6/6 paths (100%).
  • Reachability is a single recursive SQL query with a cycle guard and hop limit.
